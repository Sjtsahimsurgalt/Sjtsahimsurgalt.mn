Миний тухай

Программ хангамжийн чиглэлээр магистрын зэрэгтэй. Хүний нөөц, сургалт хөгжлийн менежер, багш, удирдлага, судалгаа, дата анализ зэрэг олон чиглэлд ажиллаж байсан туршлагатай. Мэдээллийн технологи, программ хангамжийн салбарт шинэ технологи, арга зүйд сонирхолтой бөгөөд байнга суралцахыг эрмэлздэг. Багаар ажиллах, манлайлал, дасан зохицох, асуудал шийдвэрлэх чадвартай. Эелдэг, шударга, тууштай хандлагатай бөгөөд хамтран ажиллахад үргэлж бэлэн байдаг. Төрийн бус байгууллага, сайн дурын үйл ажиллагаанд идэвхтэй оролцож, нийгэмд эерэг өөрчлөлт хийхийг зорьдог.

Вэб хөгжүүлэгч

Web програмчлалын сургалт нь вэб сайт болон веб аппликейшн боловсруулах мэдлэг, чадвар олгох сургалт юм. Энэ сургалтаар вебийн бүтэц, дизайн болон статик үйлдэлтэй веб сайтыг бүтээнэ.

Front-end болон back-end хөгжүүлэлтийн үндсийг суралцаж, бодит төсөл дээр ажиллах боломжтой. React, Node.js зэрэг технологиудыг анхан шатнаас хэрэглээний шат хүртэл суралцах.
🖥️

Мэдээллийн технологи

IT сургалт нь мэдээллийн технологийн мэдлэг, чадвар эзэмшүүлэхэд чиглэсэн сургалт юм. Энэхүү сургалтаар компьютер, програм хангамж, сүлжээ, мэдээллийн систем болон дижитал технологийг ашиглах, хөгжүүлэх суурь ойлголт ур чадваруудыг эзэмшүүлнэ.

Мэдээллийн аюулгүй байдал сүлжээний үндсийг заана. IT мэргэжилтнүүдэд шаардлагатай бүх үндсэн ур чадваруудыг олгоно.
🎨

График дизайн

График дизайн сургалт нь мэдээлэл, санааг дүрс, өнгө, шрифт болон зохиомж ашиглан илэрхийлэх мэдлэг, чадвар эзэмшүүлэхэд чиглэсэн сургалт юм. Энэхүү сургалтаар суралцагчид хэвлэлийн болон дижитал дизайны үндэс, дизайны програмууд ашиглах арга барилыг сурна.

Adobe Photoshop, Illustrator, InDesign программуудыг ашиглан мэргэжлийн график дизайн бүтээх.
🖥️

Windows орчны програмчлал

Windows орчны програмчлалын сургалт нь Windows үйлдлийн систем дээр ажиллах програм боловсруулах мэдлэг, чадвар олгох сургалт юм. Энэ сургалтаар програмчлалын суурь ойлголт, объект хандалтат програмчлал болон график интерфэйстэй програм бүтээх арга барилыг сурна.

Энэхүү сургалтын үр дүнд суралцагчид Windows үйлдлийн систем дээр ажиллах энгийн болон дунд түвшний desktop програм боловсруулах чадвартай болж, бие даан програмын төсөл боловсруулах суурь мэдлэгтэй болно.
